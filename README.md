# UP SERBER — Bio Links & Donate Page

Официальная страница-переходник и приём донатов для стримера **UP SERBER**.

## 🚀 О проекте
- **Графитовая темная тема**: глубокий графит, мягкие световые неоновые акценты (циан и янтарное пламя), плавные парящие искры.
- **Интерактивный аватар**: анимированное неоново-синее дымное кольцо с эффектом ускорения при наведении.
- **Ссылки и донаты**:
  - 🟢 **DonatePay** — донат на развитие канала
  - 💳 **Перевод по номеру карты** — копирование номера карты МИР в 1 клик
  - 🪙 **DonationAlerts** — донат со стримерскими оповещениями
  - 🔴 **YouTube** — официальный канал, стримы и ролики
  - ✈️ **Telegram** — новости и анонсы
  - 🔵 **VK** — сообщество ВКонтакте
- **Адаптивность**: идеальное центрирование на ПК и планшетах, удобная мобильная вёрстка на смартфонах.

## 🛠 Технологии
- **HTML5** — семантическая чистая разметка
- **Vanilla CSS3** — Glassmorphism, CSS Animations, Flexbox, адаптивные медиа-запросы
- **JavaScript** — Canvas-частицы, Clipboard API, Ripple-эффекты
